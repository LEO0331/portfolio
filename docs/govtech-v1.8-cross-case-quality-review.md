## Reproducible rubric

Each row is a pass, finding, or explicit evidence limit; there is no invented aggregate score. Source accuracy requires an immutable source edition, existing referenced paths, and no contradiction between the before record and the current numerical/method data. Statistical clarity requires naming the unit and denominator. Method transparency requires visible rules/assumptions and unchanged thresholds. Engineering specificity requires actual implementation/test/output links. Readability requires a four-part problem/approach/result/limits overview and the substantive detail below it. Bilingual consistency requires matching case identity/order/results and equivalent qualifications. Accessibility requires native keyboard disclosures, named navigation, captions and no page overflow. Navigation requires all case routes and original project ownership. Performance uses same-browser local resource measurements. Reproducibility uses strict inverse presentation migration against all 18 captured records plus all older frozen fixtures.

Hard gates: zero public PR destinations/workflow commentary; all nine case links; no scenario, ID, source or method drift; no fabricated outcomes; functioning routes. HTTP success alone is not source factual validation. No new upstream factual claim is inferred merely from a passing test.
